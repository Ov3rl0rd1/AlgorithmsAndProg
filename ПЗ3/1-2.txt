Задача № 1 

Функция принимает целое число n и возвращает сумму его цифр.

№ п/п   имя функции переменные	значения переменных возвращаемая команда    возвращаемое значение
1   funct(230)  n  n=230   n % 10 + funct(n // 10)  0 + funct(23)
2   funct(23)   n  n=23    n % 10 + funct(n // 10)  3 + funct(2)
3   funct(2)    n  n=2     n  2

Задача № 2
